# AETHER-NEURO-CORE
AetherNeuroCore is a high-performance biophysical simulation framework written in Python and CUDA. It bridges multi-source molecular metadata (e.g., UniProt, PubMed) to vectorized 4-state Hodgkin-Huxley differential solvers, enabling parallelized state updates for up to 100M+ neuronal compartments on single-GPU hardware
